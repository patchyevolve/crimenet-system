# Runtime dependencies for the CrimeNet API container.

# This list is derived from a static scan of the imports actually reachable
# from `api/`, `run.py`, `src/` and `loader/` — not from the developer's
# whole environment. Two groups:
#
#   * required  — imported at module scope, so the service will not start
#                 without them
#   * optional  — imported inside a function body; the pipeline degrades
#                 gracefully when they are missing. They are pinned here
#                 anyway so the container behaves the same way the verified
#                 host run did.
#

# `src.db`, and nothing on the `api -> run.py -> src.pipeline` path does.
# The pipeline writes to Postgres through raw `psycopg2` inside a try/except.
